### Exercícios da aula 2

1. Mostre que as sequências abaixo são limitadas e monótonas. Descreva o tipo de monoticidade de cada uma delas.

(a) $x_n = \frac{2n-1}{n}$

(b) $x_n = 1 + \frac{1}{3^n}$

(c) $x_n = \frac 1{n^2}$

(c) $x_n = \frac{n^2+1}{3n^2}$

2. Ache os limites das sequências acima.
3. O que se pode dizer sobre uma sequência convergente cujos  termos são todos números inteiros?
4. Ache $\displaystyle \lim_{n\to\infty}(\sqrt{n+1}-\sqrt{n})$ .
5. Se o limite de $(x_n)_n$ é $1$, mostre que existe um inteiro $m$ ≥ $1$ tal que $x_n > 1/ 2$ para todo inteiro $n$ ≥ $m$. Em particular, deduza que os elementos da sequência são maiores do que zero a partir de um certo valor de $n$.
6. Verifique se a sequência é convergente ou se o limite é ±∞. No caso convergente, determine o limite.

(a) $x_n=\frac{n+1}{2n-1}$

(b) $x_n=\frac{n^2+1}{3n}+1$

(c) $x_n=\frac{3n^2+1}{2n^2+n}$

(d) $x_n=\frac{n^2+1}{3n^2}$
