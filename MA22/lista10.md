# Exercícios da aula 10

Resolva esses exercícios somente usando o conteúdo da aula.

1. Calcule a área determinada  $f(x)=x$ e o eixo $Ox$ no intervalo [0, 1] usando soma de Riemann.
2. Seja $f$ definida em $\R$ por $f(x)=1$ se $x\neq 1,3,5$ e $f(1)=f(3)=f(5)=0$. Usando soma de Riemann, $\int_0^6 f(x)\,\mathrm{d}x$=6?
3. Seja $f : [−a, a] \to\mathbb{R}$ uma função tal que $f(x) = f(−x)$, para todo $x ∈ [−a, a]$ ($f$ é uma função *par*).  Mostre que $\int_{-a}^a f(x)dx = 2\int_{0}^a f(x)dx$.  
4. Seja $g : [−a, a] \to\mathbb{R}$ uma função tal que $g(x) = −g(−x)$, para todo $x ∈ [−a, a]$, ($g$ é uma função *ímpar*). Mostre que  $\int_{-a}^a g(x)dx = 0$.
5. Calcule $\int_{-a}^a (x^2 + x+\sin x) dx$.
6.  Justifique a desigualdade   $\int_0^1 \frac 2{1+ x^2}\,\mathrm{d}x \leq 2$.
